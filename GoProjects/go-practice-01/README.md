## Проверенные данные

### Карточка
- Изменение значения переменных в коде изменяет соответсвующие им строки в выводе программы

### Конвертер
Проверенные значения: 
| Ввод | Полных часов | Оставшихся минут | Поведение |
|---:|---:|---:|---|
| `0` | 0 | 0 | Корректный результат |
| `59` | 0 | 59 | Корректный результат |
| `60` | 1 | 0 | Корректный результат |
| `125` | 2 | 5 | Корректный результат |
| `1500` | 25 | 0 | Часы не обнуляются после 24 |
| `-1` | — | — | Сообщение о недопустимом отрицательном значении |
| `abc` | — | — | Сообщение об ошибке чтения числа |

### Статусы
Проверенные сценарии:
| Сценарий | `statuses` | `append` | Результат |
|---|---|---|---|
| 1. Обычный | `{"new", "in_progress", "done", "done"}` | Включён (`new`) | Всего 5, завершено 2 |
| 2. Пустой список | `[]string{}` | Временно отключён | Всего 0, ни одной нумерованной строки, завершено 0 |
| 3. Одна задача | `[]string{"done"}` | Временно отключён | Всего 1, завершено 1 |
| 4. Нет завершённых | `[]string{"new", "new"}` | Временно отключён | Всего 2, завершено 0 |
- `statusLabel` корректно определяет неизвестный статус
- `countStatus` корректно работает при пустом входном списке статусов

### Список задач
Проверенные сценарии:
| Сценарий | Результат |
|---|---|
| Поиск ID=2 | Получен ненулевой указатель |
| `Complete()` по ID=2 | Во **всём срезе** статус этой задачи `done` |
| `SetPriority(3)` | `true`, приоритет изменён |
| `SetPriority(0)` | `false`, прежний приоритет сохранён |
| `SetPriority(4)` | `false`, прежний приоритет сохранён |
| Поиск ID=99 | `nil`, без паники |
| Поиск в `[]Task{}` | `nil` |
| `Task{}` | Все поля имеют нулевые значения |
| `tasksByStatus(tasks, "done")` | Получен срез только выполненных задач |
|`tasksByStatus([]Task{}, "done")`| Получен пустой срез|
